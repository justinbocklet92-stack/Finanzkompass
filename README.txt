INSTALLATION AUF DEM IPHONE
1. Lade alle Dateien dieses Ordners auf einen HTTPS-Webhost (z.B. GitHub Pages oder Netlify).
2. Oeffne die URL in Safari.
3. Tippe auf Teilen > Zum Home-Bildschirm.
4. Nach dem ersten Online-Laden funktioniert die App auch offline.

WICHTIG: Ein lokaler HTML-Datei-Download installiert keine echte PWA. iOS verwendet lokal gespeicherte App-Daten nur innerhalb dieser Installation/Website. Sicherung ueber Backup exportieren und JSON importieren. Nicht ungeschuetzt auf oeffentlichen Computern verwenden.
